# Write Radio Script

## Overview

This skill guides the creation of radio scripts optimized for recruitment and employer branding campaigns. It applies the four proven narrative structures — Hook→Tension→Reveal, In Medias Res, Mirror, and Open Question — within the strict constraints of 30" and 15" audio formats.

**Core principle:** A great radio script is not a description of a job. It is a moment of identification. The candidate must hear themselves in the spot before they hear the brand.

## Conventions

- `{skill-root}` — this skill's installed directory
- `{project-root}` — project working directory
- Format targets: 30" = 70–75 words max; 15" = 35–38 words max

## Format Reference

| Format | Words (ideal) | Words (max) | Tempo |
|--------|--------------|-------------|-------|
| 30" | 70–75 | 80 | ~2.5 words/sec |
| 15" | 35–38 | 42 | ~2.5 words/sec |

**Temporal structure (30"):**
```
0"–3"   → HOOK — pattern interrupt, capture attention
3"–22"  → BODY — tension, narration, emotional journey
22"–27" → REVEAL — pivot or confirmation
27"–30" → CTA — short, memorable, repeated
```

## Stage 1: Brief Intake

Collect the following before writing a single word:

**Required inputs:**
1. **Target profile** — Who is this spot speaking to? (Be precise: "infirmier IFSI 22 ans IDF" not "jeunes professionnels")
2. **Single insight** — What does this candidate want that they won't say out loud?
3. **Brand promise** — What does joining this organization do FOR the candidate (not what the candidate does for the org)?
4. **Format** — 30" only / 15" only / both (30" + 15" teaser)
5. **Tone** — Authentic/raw / Warm/human / Challenge/defiance / Ironic/Gen Z
6. **CTA** — URL, search term, or phone? (max 3 words)
7. **Production context** — In-house or external? Actors or real employees?

**If inputs are incomplete:** Ask only for what is missing. Never assume tone or target without confirmation.

## Stage 2: Structure Selection

Based on the brief, recommend one primary structure. Present the logic briefly:

### Structure A — Hook → Tension → Reveal (3 compressed acts)
**Best for:** Changing a negative perception about the employer or the role.
**When to use:** The target has a preconception that needs inverting.
- Act 1 (0"–10"): Establish a situation the candidate recognizes
- Act 2 (10"–20"): Intensify the tension — make the problem feel real
- Act 3 (20"–27"): Reveal that recontextualizes everything
- CTA (27"–30"): Short, direct, twice if possible

### Structure B — In Medias Res
**Best for:** High-action roles (emergency services, field work, research crises).
**When to use:** The role has a vivid, recognizable moment of peak intensity.
- Open in the middle of the scene at maximum tension
- No setup, no introduction — the listener is inside the action
- Pull back to reveal the brand only after the scene is lived

### Structure C — Mirror (opening = closing, inverted meaning)
**Best for:** Roles that carry a stigma or misunderstanding (invisible work, underpaid sectors).
**When to use:** The negative perception IS the hook — and the closing reframes it as strength.
- Open with the negative label ("Je suis invisible")
- Build the reality that contradicts or redeems it
- Close by repeating the opening — but now it means something different

### Structure D — Open Question
**Best for:** Challenge-based recruiting (military, elite research, demanding roles).
**When to use:** The target is motivated by pride and the desire to prove themselves.
- The question is a direct challenge ("Peux-tu le faire ?")
- The script builds context that makes the question impossible to ignore
- Never answer the question — leave it open for the listener to answer

## Stage 3: Hook Design

Design the hook before writing the full script. The hook is the first 3 seconds.

**Six hook types (select one):**

| Type | Mechanism | Example |
|------|-----------|---------|
| Unexpected sound | Pattern interrupt — triggers orientation reflex | 1.5" of silence before any voice |
| Mental demand question | Captures cognition — listener must answer internally | "C'était quand, la dernière fois que tu as eu peur de ne pas y arriver ?" |
| Polarizing statement | Cognitive dissonance — brain wants to resolve | "L'Institut Curie ne cherche pas des collaborateurs. Il cherche les bons." |
| Tone break | The shift itself is the hook | Open warm → cut to something stark |
| Unexpected voice | Difference = attention | Child, strong regional accent, non-actor |
| In medias res sound | Listener enters a scene already in motion | [SFX: door slam + mid-conversation dialogue] |

**Do NOT open with:**
- A generic jingle
- "Bonjour !" or any greeting
- The brand name
- A slow build
- An abstract statistic

## Stage 4: Script Writing

Write the full script in the following format:

```
---
CLIENT: [Brand name]
FORMAT: [30" / 15"]
STRUCTURE: [A / B / C / D]
TARGET: [Exact profile]
---

[SFX: description of sound design]
VOICE 1 (casting note): "Dialogue line."
[Pause: X seconds]
VOICE 2: "Response line."
[SFX: transition if needed]
NARRATOR: "Brand message."
[Pause: X seconds]
NARRATOR: "CTA — repeated."

---
WORD COUNT: XX words
ESTIMATED DURATION: XX"
SILENCE BUDGET: X" total
```

**Silence rules (critical):**
- 0.3"–0.5" — natural pause between ideas
- 0.7"–1" — pre-reveal or post-strong-statement focus
- 1.5"–2" — maximum dramatic tension
- Never exceed 3" (radio standard triggers technical alarm)

**Language rules:**
- Zero HR jargon ("rejoignez notre équipe dynamique", "environnement stimulant")
- Zero empty superlatives ("meilleur employeur", "équipe passionnée")
- One central idea per script. Never two.
- CTA: 3 words maximum. Repeat twice.

---

## Stage 5: Validation Checklist

Run every script through this checklist before delivery:

- [ ] Hook fires in first 3 seconds (sound, question, or unexpected statement)
- [ ] Word count within format limit (30" ≤ 80 words; 15" ≤ 42 words)
- [ ] Single central idea (no list, no enumeration)
- [ ] At least one pause of 0.7"–1" for dramatic effect
- [ ] Tone coherent with brand culture (would a current employee recognize themselves?)
- [ ] CTA ≤ 3 words, repeated twice
- [ ] No HR jargon
- [ ] No empty superlatives
- [ ] Script reads naturally at 2.5 words/second
- [ ] "Penny drop" moment is clear (the listener understands the reveal before the brand speaks)

## Stage 6: 15" Teaser Derivation (if requested)

The 15" is not a shortened 30". It is a different script with a single function: **prime the listener for the 30", or drive direct action when the listener already knows the brand.**

Structure for 15":
```
0"–1"   → Hook (same logic as 30", compressed to 1 sound or phrase)
1"–11"  → Single claim — the one thing that changes everything
11"–15" → CTA — identical to the 30" version for consistency
```

**Rule:** Write the 15" after the 30" is locked. Extract the most emotionally loaded 10 seconds of the 30" body, not the opening.

---

## Stage 7: Production Notes

Deliver a production brief alongside each script:

**Casting:**
- Voice type (actor / real employee / voice of the target)
- Age range, gender if relevant, regional accent if strategic
- Emotional register (exhausted, calm, proud, wry, direct)

**Sound design:**
- Ambient sounds (clinical, industrial, outdoor, silence)
- Music: none / functional / emotional layer — specify tempo and mood
- Silence usage: where, why, how long

**Authenticity flag:**
- If the campaign promises proximity and human culture → no glossy production
- If the campaign promises excellence and precision → clean production acceptable
- Reference: Armée de Terre 2024 (zero music, real soldiers, real sounds) = the benchmark for authenticity-as-message

## Twist vs Confirmation: Choosing Your Reveal

| | Twist (break) | Confirmation (amplify) |
|---|---|---|
| Principle | Reorient the listener's understanding at the end | Confirm and deepen what they suspected |
| Effect | Surprise, strong memorability | Satisfaction, emotional adhesion |
| Risk | Too dramatic → brand disappears | Too predictable → boredom |
| **Best for** | Changing a perception (recruitment) | Reinforcing a promise (employer brand) |

**The false trail rule (for twist):**
1. Build Trail A (15"+ of credible misdirection)
2. Deliver the pivot (one word, sound, or reframe)
3. Hold 0.7"–1" of silence (the "penny drop")
4. Brand speaks only after the listener has understood — never before
